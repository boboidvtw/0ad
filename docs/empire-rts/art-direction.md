# 美術規格與資產清單

更新日期：2026-09-06。狀態：文字方向已確認，概念圖、模型與正式素材尚未製作。[計畫](plan.md) · [進度](progress.md)

## 視覺方向

採略帶風格化、輪廓清楚的 3D 歷史戰爭美術，讓玩家在正常 RTS 鏡頭下辨認兵種、陣營、建築功能和時代。用材質、屋頂、裝備和動作表現時代變化；同類建築跨時代保留可辨認的量體關係。這是原創方向，不複製 Empire Earth 的原始視覺資產。

- 地形色彩較收斂，單位輪廓與可操作物件有足夠對比。
- 玩家色放在旗幟、衣物或載具色塊的穩定位置；兵種辨識也依靠輪廓和武器，不只靠顏色。
- 同一類人物共用合理骨架與基礎動作；必要的攻擊差異另做動畫。
- 建築以牆、屋頂、門窗、塔及裝飾模組組合，保持同文明的一致材質語言。
- UI 以清楚閱讀為先，科技圖示共用背景、構圖、邊框及狀態標示規則。

精確色票、單位比例、貼圖尺寸、模型面數與動畫清單在首批樣板進入遊戲並完成效能量測後固定；目前不虛構已完成的技術規格。

## 製作順序

1. **暫用資產**：沿用適合的 0 A.D. 素材或簡模，逐項記錄來源，驗證玩法、碰撞範圍和比例。
2. **概念與樣板**：製作一個工人、一個戰鬥單位、一組建築及 HUD 樣板；建立視覺規格。
3. **遊戲內垂直切片**：檢查輪廓、動畫、玩家色、選取狀態、畫面一致性與效能。
4. **模組化擴充**：通過驗收後再擴充其餘兵種、建築與時代，逐步替換暫用資產。

AI 可協助概念探索、圖示草稿與貼圖方向；生成圖片不等於可用 3D 資產。正式模型仍需拓樸與比例整理、UV、材質、必要綁骨與動畫、匯出和遊戲內驗收。可評估使用 Blender 製作，但須先驗證與固定引擎版本的匯入流程及所需工具版本。

## 資產紀錄規格

正式導入前建立資產登錄表，每一項至少包含：

| 欄位 | 要記錄的內容 |
| --- | --- |
| ID、名稱、用途 | 對應 Axx 與使用單位／建築 |
| 狀態 | 待選定、暫用、製作中、待驗收、正式 |
| 作者與來源 | 原始網址或上游檔案路徑、版本、取得日期 |
| 授權與署名 | 完整授權名稱、證據位置、修改與散布條件、所需署名 |
| 原始檔／匯出檔 | 可編輯檔和遊戲使用檔的位置、工具版本 |
| 技術資料 | 比例、面數、貼圖、骨架、動畫、匯出設定 |
| 驗收證據 | 測試地圖、引擎版本、截圖或錄影、效能結果、已知問題 |

0 A.D. 根目錄 LICENSE.txt 對不同目錄有不同授權規定；art/audio 一般列為 CC BY-SA 3.0，仍需查看該資產及子目錄的具體授權。不能把程式授權當作所有素材的授權。公開發行前檢查實際分發清單及署名。

M1 已引用部分官方暫用素材；未新增正式模型／圖像，沒有已核准的採購或外包項目。未經確認來源與授權的素材不進正式發行包。

## 遊戲內驗收

- 正常鏡頭下能區分工人、戰鬥兵種、建築功能與玩家陣營。
- 模型方向、尺寸、落地高度、選取圈和碰撞／通行表現符合用途。
- 移動、攻擊、工作等必要動畫正常，沒有明顯穿模或缺失貼圖。
- UI 在測試解析度下可讀，禁用、選取和研究中狀態可區分。
- 在記錄的硬體與單位量下測試；門檻依基線量測確立。
- 授權來源、可編輯原始檔及匯出設定齊備，另一位開發者能重現匯出。
