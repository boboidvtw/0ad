依序建立 epoch 文明、單位／建築模板、duel 地圖及啟動入口，再驗證採集、建造、訓練。科技 ID 可先建立作鎖定依據，不能以免費完成鐵器科技繞過 T05。

## 證據與完成門檻

每次實測記錄 commit、官方 runtime 版本、地圖／seed、步驟、預期／實際、通過或失敗與證據位置。引擎模擬、模板靜態檢查及 UI 操作分別記錄，不互相替代。畫面案例保存截圖；流程保存重播或可重現步驟。公開證據排除私人路徑及憑證。

必要案例通過且引擎日誌無未處理錯誤／警告，才可完成對應 T04、T05 或 T06。案例不適用需記錄規格變更理由，不能默默略過。T06 完成才代表 M2 完成；效能、多人、存讀檔及通用 AI 另有 T12–T14。
