# T10 暫用素材與匯入樣板

範圍：一個靜態房屋簡模，驗證可編輯來源、確定性匯出、R28原生匯入、正常鏡頭顯示／玩家色／選取與保留M2規則。獨立測試地圖，不把暫用簡模直接替換M2正式場景。

選房屋是因為靜態資產能形成完整且小型的匯入流程。本機未找到Blender executable，因此以Python標準庫產生原創幾何與色塊貼圖；沒有假稱Blender或人物動畫工作流程已驗收。原生R28材質與引擎保留，沒有新增C++或付費工具。
