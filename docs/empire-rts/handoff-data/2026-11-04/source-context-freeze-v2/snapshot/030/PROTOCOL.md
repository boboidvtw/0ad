# NDJSON v1 exact protocol

single child Python `-u .../t17-save-five-mod-capture.py`，無shell；Node spawn一次。stdin/stdout為protocol only，stderr為bounded diagnostics。每frame strict UTF8、JSON object、own key set exactly、duplicateJSONkeys拒絕、NaN/Infinity拒絕、integer有界。JSON遇unsupported type/未知key/超限即FAULT，沒有eval或任意filename/command/pathcallback。

1. Node→Python `{"v":1,"kind":"BEGIN","outputLeaf":"..."}`。expected authority/5layer roots/limits不是caller參數，來自已核工具固定source與bound AUDIT；不得有 public enable/test/fakeexpected 選項。
2. Python完成authority首pass/root reservation/capture後，按 UTF8 path bytes lexicographic 固定序（不依hostlocale）送零或多個 `{"v":1,"kind":"SOURCE","index":0,"vfs":"...","mod":"...","sha256":"64hex","bytes":N,"bodyBase64":"..."}`。每SOURCE只一次，index連續、fresh bytes由Python捕獲；Node檢 length/SHA/canonicalbase64/總limit。非JS仍送或保留一致source pack以供metadata；Node不把mod/name當身份proof。
3. Python→Node `{"v":1,"kind":"CAPTURED","captureId":"64hex","sourceCount":N,"selectedDigest":"64hex","layers":[],"selected":[],"archive":{},"unsupportedRuntimeRules":[]}`。nested row schema source implementation前須照本契約固定：layers row為 name/rootKind/rootDisplay/entries；entry vfs/sourceDisplay/sha256/bytes；selected row index/vfs/mod/sha256/bytes/shadowed/archiveEntry-or-null/defaultLoaderFolder-or-null/realm；shadowed row mod/sourceDisplay/sha256；archive expectedSHA/actualSHA/size/chunkBytes/chunkCount/authorityKind='VERIFIED_HELD_FD_BYTES'。captureId=SHA256 exact canonical compact JSON of {version:1,archiveExpectedSHA,selectedDigest}；selectedDigest=SHA256 newlinejoined sorted `vfs+NUL+mod+NUL+sha256+NUL+bytes` UTF8。Python保留此實際metadata，不採信Nodeecho改寫。
4. Node -> Python FINISH exact frame is normative ANALYSIS-SCHEMA.json root. It contains v/kind/captureId/analyses/tool only. Each analyses row exact index/sha256/analysis. analysis is oneOf PARSED, BLOCK_PARSE_ERROR, BLOCK_UTF8_ERROR, or non-JS null. vfs is mandatory in each nonnull variant and equals selected[index].vfs. All nested function/call/direct-writer/alias-writer/assignment/update/delete/declaration rows, nullability, keys, enums and bounds are fixed in schema; SOURCE-RELATIONS.json provides mandatory source-dependent checks. Python synthesizes the three fixed JSON outputs using its private capture metadata. Node supplies no output names or archive/path/closure authority. Missing/extra/wrong fields are terminal fault, not projected or guessed. These structures retain unresolved source evidence and never certify semantic writer closure.
5. Python先核 FINISHlimits/schema/captureId/rows/fullsource digest以及held loose/anchors，再 exclusive寫三結果與hash manifest（含source/output hash），固定status/sourceClosure/native，最後completed.json。manifest精確只hash已close的effective/layer-metadata/archive-auth/capture-inputs/三analysis files，排除仍可能更新的raw logs/diagnostics與manifest/completed/fault本身；此排除完整列入manifest欄位，不聲稱完整rawseal。raw logs可另記已durableprefix offset+SHA但不能當wholefilehash，terminal raw封存若需新增seal必另契約，不在此slice虛構。送 `{"v":1,"kind":"COMPLETED","captureId":"...","status":"CAPTURE_COMPLETE_CANDIDATE_ONLY|CAPTURE_COMPLETE_WITH_ANALYSIS_BLOCKS","artifactHashes":{},"sourceClosure":false,"native":false}`，flush且exit0。artifactHashes只fixed三json+manifest，completed不自雜湊。Python產出檔只採其內部固定相對path；Node無filename欄位。
6. 任意phase可 Python→Node `{"v":1,"kind":"FAULT","phase":"...","code":"...","durableFault":false或true}`，之後非0exit且無COMPLETED。若emit也失敗僅stderr/exit/已有partial，結果UNKNOWN。Node parse/Acorn fatal/protocol failure可送一次 `{"v":1,"kind":"ABORT","code":"NODE_PROTOCOL|NODE_ANALYSIS|NODE_LIMIT"}`（只CAPTURED後）；之後close並reap，不retry。子程序意外退出、無response、duplicateSOURCE、CAPTURED前FINISH/ABORT或COMPLETED後extraframe皆BLOCK/UNKNOWN。

## Normative design-fix precedence

ANALYSIS-SCHEMA.json plus SOURCE-RELATIONS.json and LIMITS.json are the exact shared analysis interface. JSON Schema maxLength is a coarse Unicode codepoint bound; UTF16/codeunit and UTF8-byte relationships are additional mandatory gates. No jsonschema dependency installation is implied: the Python author implements the finite stdlib validator from this design. No unknown fields or implicit optional keys are accepted. Escaped lone JS surrogate codeunits in evidence values are preserved via JSON escapes; invalid UTF8 frame bytes still fail.

ZIP compatibility clarification from full Python review (existing obligations, no scope expansion): compute seek result by whence before checking range; legal negative SEEK_END offsets are supported. read()/read(-1) normalizes bounded remaining EOF suffix before allocation; no readall of archive from0. Check orig_filename before ZipInfo truncates NUL for filename. Freeze actual Python/stdlib/native extensions and Node/Acorn; caller SHA is not attestation. Resourceclose/timeout/stdout failure semantics stay unchanged.
