# M7.6 試玩包：邀請訊息與回饋問卷

目標是找 1–3 個人照 [INSTALL.md](INSTALL.md) 自己安裝，玩一局 1 對 1 對 AI，再回答 5 題。整理結果寫在 [m7.6-feedback.md](m7.6-feedback.md)，用來決定 M8 做哪個方向。

這份文件同時要驗證 M7.4 留下的未驗證步驟：Finder 雙擊安裝、Mod Selection 啟用，以及開局時把 AI 改成 Epoch Petra。

## 找誰

| 條件 | 為什麼 |
| --- | --- |
| 有 Mac（最好是 Apple Silicon） | 只有 macOS 驗證過 |
| 至少 1 人**沒玩過** 0 A.D. | 才看得出安裝說明和開場說明夠不夠清楚 |
| 願意花約 40 分鐘 | 安裝約 15 分、一局 15–20 分、問卷 5 分 |

## 邀請訊息（複製後自己傳）

> 嗨，我做了一個即時戰略遊戲的小試玩版，想請你幫忙玩一局，大約 40 分鐘（含安裝）。
>
> 1. 需要 Mac，先到 <https://play0ad.com/download/> 裝免費遊戲 0 A.D.（要 Release 28）。
> 2. 到 <https://github.com/boboidvtw/0ad/releases/tag/v0.5.0> 下載 `epoch_rts-0.5.0.pyromod`。
> 3. 照這份說明安裝並開一局：<https://github.com/boboidvtw/0ad/blob/master/docs/empire-rts/INSTALL.md>
>
> 遊戲有 16 個時代（史前→太空），預設從青銅開局；想試別的時代，可以在對戰設定的「玩家」分頁改「開局時代」「結束時代」。
>
> 請**不要先問我**，盡量自己照說明做；卡住的地方正是我最想知道的。玩完回答下面 5 題就好，輸贏都沒關係。

## 回饋問卷（5 題）

1. **安裝**：從下載到開始第一局，有沒有卡住？
   - 順利 ／ 卡住了：卡在第幾步、畫面上看到什麼？
2. **一局**：大概玩了幾分鐘？結果是贏、輸，還是沒打完？你升到哪個時代？AI 進攻時有沒有帶騎兵或攻城武器，感覺怎樣？
3. **想再玩嗎**：1 到 5 分（1 = 不想再碰，5 = 現在就想再開一局）。
4. **下一版最想要哪一個**（選一個）：
   - A. 更多內容：更多單位與建築（例如帝國以後的時代也有新單位）
   - B. 特色玩法：例如空軍、跨時代的特殊單位
   - C. 手感與畫面：動畫、音效、看起來不像別的遊戲換皮
   - D. 其他：＿＿＿＿
5. **最不順的一件事**：整局中最困惑、最卡或最煩的是什麼？

選填：如果遇到錯誤或當機，請附上 `~/Library/Application Support/0ad/logs/mainlog.html`。

回答可以直接回覆給邀請你的人；有 GitHub 帳號的話，也可以把錯誤開成 Issue：<https://github.com/boboidvtw/0ad/issues>（公開，請先刪掉 log 裡的使用者名稱與路徑）。

## 怎麼對應到決策

| 題目 | 用來判斷 |
| --- | --- |
| Q1 | INSTALL.md 哪一步要改；M7.4 的未驗證步驟是否成立 |
| Q2 | M7.2 的真人時長（10–20 分）是否成立；超過 20 分要重看平衡（見 decisions.md） |
| Q3 | 整體是否值得往下做 |
| Q4 | M8 選 A／B／C（RESET-PLAN 第 7 節） |
| Q5 | 開場說明或手感要先修的項目 |

## 隱私

repo 是公開的。寫進 `m7.6-feedback.md` 時，試玩者一律用 P1／P2／P3 代稱，不寫姓名、帳號或聯絡方式；`mainlog.html` 不提交進 repo，只摘錄錯誤訊息（並刪掉裡面的使用者名稱與路徑）。
